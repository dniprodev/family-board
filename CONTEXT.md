# Family Board

Family Board is a shared page of links: one person maintains it, and other people read it through a link.

## Page and content

**Page**:
A single shared collection of link items with one editor and read-only readers.
_Avoid_: Board, document, paste

**Link item**:
A saved link with a title and destination URL that belongs to a page.
_Avoid_: Card, bookmark, entry

## Access and sharing

**Read link**:
An unguessable URL that grants permission to view a page.
_Avoid_: Public link, viewer link

**Edit link**:
A separate unguessable URL that grants permission to change a page.
_Avoid_: Admin link, manage link

**Bearer-link access**:
Access based on possession of an unguessable link rather than on an account, password, or identity.
_Avoid_: Anonymous authentication, public access

**Editor**:
The person who maintains a page through its edit link.
_Avoid_: Owner, administrator

**Reader**:
A person who views a page through its read link and cannot change it.
_Avoid_: Viewer, collaborator
